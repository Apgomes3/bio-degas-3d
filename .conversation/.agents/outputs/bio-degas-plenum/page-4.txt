EDP · Bio/Degas
CRATE COUNT
N = ceil(mediaVolumeM3 ÷ 0.238). If the resolved value is non-finite or ≤ 0, no designer is rendered.
Recommended candidate generation
• Fix wall = 80 mm and nominal stack = 3.
• positions = ceil(N ÷ 3). For rows r ∈ {1, 2}, columns = ceil(positions ÷ r).
• candidateLength = max(3405 + 800 + 2×80, columns×740 + 800 + 2×80).
• candidateWidth = max(2005 + 2×80, rows×1040 + 2×80).
• Discard candidates above 9000 × 2250; sort by area, then length, then rows. Select the first.
• If no candidate fits, fallback is rows=2, length=9000, width=2250.
