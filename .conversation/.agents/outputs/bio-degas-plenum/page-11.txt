State and persistence
•
React Query key: bio-degas-plenum-layout + systemId + bookId; GET is enabled only with both IDs and a positive crate 
count.
•
Saved layout is merged over a fresh recommendation; missing stacks are regenerated. Recommended resets local layout.
•
Save is blocked by assessment errors or stale media. PUT includes design_book_id and source_crate_count, but server 
recomputes the source.
•
Saved layout creates/updates one project equipment item and one generated plenum line plus a separate tray line 
quantified by tray_count.
•
Draft/In Progress reads live data; For Review/Approved/Released reads the corresponding snapshot. Database triggers 
prevent mutation of frozen design-book states.
STALE RESULT
Staleness = preview.is_stale OR saved.source_crate_count ≠ current crateCount. The UI preserves the saved layout but 
requires Biological Media recalculation before saving.
